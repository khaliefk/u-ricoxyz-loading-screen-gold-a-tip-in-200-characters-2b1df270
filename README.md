One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, for the [make.fun bounty](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

## The entry

> Tip: the agent finished in 9 seconds. You now have 45 minutes to learn what 'done' meant to it.

The agent is fast and confident. The developer is the one who finds out what that confidence actually shipped. Both sides of the keyboard feel seen.

## Run it

```sh
python3 main.py
# writes the tip to /output/entry.txt (95 characters, one line)
```

`main.py` holds the tip as a single string, checks it is 1 to 200 characters, a single non-blank line, then writes it to `/output/entry.txt`.
